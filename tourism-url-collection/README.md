# 観光地URL収集シート

全国の都道府県・市区町村の公式ホームページ等から観光地情報のURLを手作業で集めるための入力用エクセルです。

- `prefecture_tourism_urls.xlsx`
  - まず47都道府県の公式ホームページ(観光課・観光連盟サイト等)を調べる用。都道府県順に47行を事前入力済み
- `municipal_tourism_urls.xlsx`
  - 「記入ルール」: 進め方・列の説明
  - 「観光地URL入力」: 全国1,739市区町村を都道府県順に事前入力済み。URL等を埋めていく入力シート
  - 「進捗サマリー」: 都道府県ごとの入力件数・入力率を自動集計
  - 1人で全件をこなすのは現実的でないため、まずは `prefecture_tourism_urls.xlsx` で都道府県レベルを埋め、
    市区町村単位はオープンデータの自動収集や協力者との分担と組み合わせる想定

市区町村の一覧は [geolonia/japanese-addresses](https://github.com/geolonia/japanese-addresses) の住所データから抽出し、
政令指定都市の区(例: 札幌市中央区)は親市(札幌市)にまとめています。

集まったデータは、将来的に観光地オープンデータベース用の別リポジトリへ整理・移行する想定です。
